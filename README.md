# Drivers – Helper!

Instaladores oficiais de tokens e cartões para Certificado Digital A3, usados pela página
https://arhelper.com.br/drivers.

Os instaladores ficam na raiz deste repositório. A página usa o endereço
`https://github.com/HelperSolutions/drivers/raw/main/<arquivo>`, então para atualizar um driver
basta substituir o arquivo mantendo o **mesmo nome**.

| Dispositivo | Arquivo |
|---|---|
| Token SafeNet 5110/5300 (Windows 64) | safenet-sac-windows-x64.msi |
| Token SafeNet 5110/5300 (Windows 32) | safenet-sac-windows-x86.msi |
| Token SafeNet 5110/5300 (macOS) | safenet-sac-macos.dmg |
| Token ePass2003 (Windows) | epass2003-windows.exe |
| Token ePass2003 (macOS) | epass2003-macos.pkg |
| G&D StarSign / SafeSign (Windows 64) | safesign-windows-x64.exe |
| G&D StarSign / SafeSign (Windows 32) | safesign-windows-x86.exe |
| G&D StarSign / SafeSign (macOS) | safesign-macos.dmg |
| Cartão AWP (Windows) | awp-cartao-windows.exe |
| Leitora de cartão (Windows) | leitora-windows.exe |
