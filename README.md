# Drivers – Helper!

Instaladores oficiais de tokens e cartões para Certificado Digital A3, usados pela página
https://arhelper.com.br/drivers.

Os instaladores ficam na raiz deste repositório. A página usa o endereço
`https://github.com/HelperSolutions/drivers/raw/main/<arquivo>`, então para atualizar um driver
basta substituir o arquivo mantendo o **mesmo nome**.

| Dispositivo | Arquivo | Versão |
|---|---|---|
| Token SafeNet 5110/5300 (Windows 64) | safenet-sac-10.8-windows-x64.msi | SafeNet Authentication Client 10.8.261 |
| Token SafeNet 5110/5300 (Windows 64, alternativa) | safenet-sac-10.7-windows-x64.msi | SafeNet Authentication Client 10.7.167 |
| Token ePass2003 (Windows 32/64) | epass2003-windows.exe | EnterSafe ePass2003 1.1.16.330 |
| G&D StarSign / SafeSign (Windows 64) | safesign-windows-x64.exe | SafeSign IC 3.0.124 |
| Cartão AWP / IDEMIA (Windows 64) | awp-windows-x64.msi | IDEMIA AWP 5.3.7 SR1 |

Hashes SHA-256 em `SHA256SUMS.txt`.
